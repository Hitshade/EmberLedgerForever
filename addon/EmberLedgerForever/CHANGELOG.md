# 0.5.0

First release prepared for CurseForge, bringing the Forever alpha work into one compact farming addon.

- Track farming loot, quantities, confirmed looted coin, active session time, estimated value and estimated gold/hour.
- Start sessions automatically on login, with Pause/Resume, Stop and New in Options.
- Review the last 20 nonempty sessions per character in a separate History panel.
- Use manual prices, TSM market data, Auctionator data or vendor fallback.
- Choose Modern, native Forever or minimal Classic styling, with resizing, locking, scale and background opacity controls.
- Show/hide the tracker or open Options through the bundled minimap/broker launcher.
- Refine Forever title bars, metric spacing, column alignment and window borders.

The 0.5.0 preparation changes version metadata, documentation, licensing notices and packaging. Gameplay behavior remains that of the final 0.4.4-alpha build. Existing character settings and saved session data are retained.
